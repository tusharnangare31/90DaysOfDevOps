# 90 Days DevOps Learning Plan

## Current Level
I am an IT student with basic knowledge of Linux commands and Docker. I know how to build Docker images, run containers, and write Dockerfiles. I also have very basic knowledge of Kubernetes.

## What DevOps & Cloud Means to Me
DevOps is not just a tool; it is a process and culture focused on automating software development, deployment, monitoring, and infrastructure management to deliver applications faster and more efficiently.

Cloud Engineering helps organizations scale applications and services reliably for a large number of users.

## Why I Am Learning DevOps & Cloud
I am learning DevOps and Cloud because I want to contribute to real-world application delivery and deployment at scale. I like the idea of building systems that can serve huge audiences efficiently and reliably.

I also want to develop strong practical skills in automation, infrastructure, deployment, and cloud technologies to become industry-ready.

## My 90-Day Goals

### Goal 1
Build strong Linux, Git, Docker, and Networking fundamentals.

### Goal 2
Learn CI/CD pipelines using Jenkins and GitHub Actions.

### Goal 3
Deploy and manage applications on Kubernetes and AWS.

## Core Skills I Want To Build

- Linux troubleshooting and shell scripting
- CI/CD pipeline creation and automation
- Kubernetes deployment and debugging

## Weekly Time Commitment

- Weekdays: 2–3 hours daily
- Weekends: 5–6 hours daily

## How I Will Stay Consistent

- Practice daily without skipping
- Build projects alongside learning
- Push code and notes regularly on GitHub
- Share progress publicly on LinkedIn
- Focus on discipline and consistency instead of perfection

## Final Target
By the end of these 90 days, I want to confidently deploy, automate, and manage applications using modern DevOps tools and cloud platforms.
I want to have a strong portfolio of projects demonstrating my skills in Linux, CI/CD, Kubernetes, and AWS. I also want to be ready to apply for entry-level DevOps and Cloud Engineering roles with practical experience and knowledge.
